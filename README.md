# Exploratory Data Analysis (EDA) Project

## Objective
Analyze a dataset to uncover patterns and trends using statistical summaries and visualizations.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Features
- Data Inspection
- Missing Value Analysis
- Duplicate Detection
- Statistical Summary
- Histograms
- Boxplots
- Correlation Heatmap
- Pair Plot

## How to Run

1. Install dependencies

pip install -r requirements.txt

2. Run the project

python eda_analysis.py

## Expected Outcome
Develop analytical thinking and data exploration skills by identifying trends, correlations, and key insights from data.
